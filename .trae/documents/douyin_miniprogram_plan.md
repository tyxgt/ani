# 抖音小程序首页实现计划

## 1. 需求分析

### 1.1 目标平台
- 抖音小程序（Douyin Mini Program）

### 1.2 页面功能
根据用户提供的设计图，首页需要包含：
- 背景图（中国风景：长城、天坛、山水）
- 大熊猫医生形象（居中显示）
- 音频播放按钮（右上角喇叭图标）
- 热气球和飞鸟装饰元素
- "开始探索吧！"主按钮
- 底部导航栏（探索、AI小助手、学习、我的）

### 1.3 技术栈
- Taro 3.x + TypeScript
- Less 样式
- 抖音小程序适配

---

## 2. 实现步骤

### 2.1 初始化 Taro 项目
```bash
npx degit dcloudio/uni-preset-vue#vite-ts . --force
```

### 2.2 创建页面结构
```
src/
├── pages/
│   └── index/
│       ├── index.vue      # 首页组件
│       └── index.scss     # 首页样式
├── assets/
│   ├── background.png     # 背景图
│   ├── panda.png          # 大熊猫医生图片
│   └── icons/             # 图标资源
└── App.vue                # 应用入口
```

### 2.3 页面组件设计

#### 2.3.1 首页组件结构
| 组件部分 | 描述 | 样式要求 |
|---------|------|---------|
| 背景层 | 全屏背景图 | 覆盖整个屏幕，自适应 |
| 装饰元素 | 热气球、飞鸟 | 绝对定位，动画效果 |
| 大熊猫医生 | 居中显示 | 半透明PNG，自适应大小 |
| 喇叭按钮 | 右上角音频控制 | 圆形按钮，悬停效果 |
| 主按钮 | "开始探索吧！" | 橙色渐变，圆角 |
| 底部导航 | 四个tab | 圆角背景，选中状态高亮 |

#### 2.3.2 样式设计要点
- 使用 flex 布局实现居中
- 背景图使用 `background-size: cover`
- 底部导航使用 fixed 定位

## 4. 注意事项

### 4.1 抖音小程序适配
- 使用 `tt` 对象代替 `wx`
- 注意抖音小程序的API差异
- 图片资源需使用绝对路径或网络地址

### 4.2 图片资源处理
- 背景图和大熊猫图片需要提前准备
- 使用网络图片URL或base64编码

### 4.3 性能优化
- 图片压缩处理
- 避免过度渲染
