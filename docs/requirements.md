## 1. 项目概述

| 项目 | 说明 |
|------|------|
| **产品名称** | 大熊猫博士 |
| **产品定位** | 儿童中国地理教育类小程序 |
| **目标用户** | 3-8 岁儿童（亲子使用场景，家长辅助） |
| **核心价值** | 通过交互式地图、AI 问答、动物百科等趣味形式，帮助儿童学习中国地理和自然知识 |

## 3. 用户流程

### 3.1 游客浏览路径
```
启动 App → 首页（探索页）→ 点击"开始探索吧" → 地图页 → 点击区域 → 信息卡片 → "了解更多" → 区域详情页
                                                                      ↓ 切换 Tab
                                                             AI 小助手 / 学习 / 我的
```

### 3.2 登录用户路径
```
启动 App → 自动静默登录 → 我的页 → 查看用户信息
                                         ↓
                                 设置 · 关于 · 反馈 · 分享 · 退出
```

### 3.3 AI 对话路径
```
启动 App → AI Tab → 输入问题 → （待实现）后端 AI 回复
```

## 6. 交互说明

- **登录弹窗**：在"我的"页点击"点击登录"弹出，支持微信昵称自动填充和跳过
- **地图手势**：单指拖拽平移、双指捏合缩放（0.5x-5x）、单击选择区域
- **Tab 切换**：自定义 TabBar 组件，地图和区域详情页为无 Tab 子页面
- **拼音标注**：全应用使用 `PinyinText` 组件实时计算拼音
