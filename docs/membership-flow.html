会员开通流程

这个小程序没有收银台。判断一个人能不能和熊猫博士聊天，从头到尾只看数据库里一个时间戳字段。这份文档把"谁在什么时候做什么"讲清楚。

一句话说完整个机制：「AI 对话」这个入口出不出现，只取决于 user 表里 vipExpireAt 这个时间戳有没有过期。没有支付网关、没有审核后台——你在云开发控制台手动改这一个字段，就是"开通会员"的全部操作。

01完整流程

从用户点开小程序，到你帮他开通，再到他自己看到入口重新出现，一共是这 7 步。

02入口消失在哪几个地方

非会员看不到「AI 对话」这四个字，具体是下面三处同时生效——前两处是"藏起来"，最后一行才是真正拦人的防线。

位置文件触发条件
底部 tabBar 的「AI」图标 CustomTabBar/index.vue AI_CHAT_ENABLED && isVip
地形 / 气候 / 动物详情页的「问博士」按钮 terrainDetail 等 3 个页面 同上
chat 云函数本身（服务端兜底，不可绕过） cloudfunctions/chat 查库 vipExpireAt，未过期才放行 DeepSeek，否则返回 40001

03user 表字段速查

字段谁能改说明
openid 系统自动写入 微信身份标识，唯一
userCode 系统自动生成 6 位数字，用户在"我的"页复制后报给你核对身份
vipExpireAt 只有你手动改 会员到期时间戳（毫秒）；null 或早于当前时间 = 未开通——唯一的权限判断依据
vipType 只有你手动改 'week' / 'month'，仅备注，不参与权限判断
createdAt / updatedAt 系统自动 首次登录 / 最近一次登录时间

04你要做的操作

  1. 收到识别码
    用户把「我的」页面上的 6 位识别码发给你（线下转账 + 微信私聊）
  2. 在云开发控制台找到那条记录
    数据库 → user 集合 → 用 userCode 筛选定位
  3. 按公式算出新的到期时间并写入
    填 vipExpireAt，顺手把 vipType 改成 week 或 month（公式见下）
  4. 保存，不用通知用户
    他下次切一下底部标签（比如切到「学习」再切回来），小程序会自动查到最新状态

05续费公式

新 vipExpireAt = max(当前时间, 记录里原有的 vipExpireAt) + 套餐时长
周卡 = 7 天 = 604800000 毫秒
月卡 = 30 天 = 2592000000 毫秒
用 max(...) 而不是直接从今天起算，是为了让提前续费的人不吃亏——快到期时续费，新周期会接在原有到期时间后面，而不是浪费掉还没用完的天数。

06还差两步才能真正生效

  • 部署三个云函数：login / chat / getMembership getMembership 是新增的，目录下要先执行一次 npm install 再上传
  • 把 user 集合的数据库权限设成「所有人不可读不可写」 前端全程不直接读写这张表，都是走云函数，锁死更安全

07常见疑问

我改完数据库，用户要等多久才能看到变化？
不用等 token 过期（最长可能快 7 天）。只要他在小程序里切换一次底部标签，哪怕是切到「学习」再切回来，onShow 就会静默查一次最新状态，AI 图标立刻出现。
用户会不会看到「请开通会员」之类的提示？
不会。整个流程里没有任何弹窗或提示文案——非会员从头到尾就是看不到「AI」这个入口，好像这个功能根本不存在一样。
万一有人绕过界面，直接调用 chat 云函数呢？
chat 云函数自己会再查一次 vipExpireAt，没过期才会真的去问 DeepSeek；查询本身失败也按未开通处理。这是唯一一道改不掉、绕不过的检查。
